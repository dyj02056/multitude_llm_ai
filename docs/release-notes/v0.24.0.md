고도화 계획(v0.24.0~v0.30.0)의 **1단계: 기반 정리** 버전입니다. 쓰는 사람이 보기에 새 기능은 **기록 최대 개수 설정** 하나이고, 나머지는 앞으로의 기능을 얹기 위한 구조 정리입니다.

## 바뀐 점

### 기록 저장 구조 (Windows 앱 · 크롬 확장)

- 기록을 **색인 + 기록별 저장**으로 나눴습니다. 답변 하나가 끝나면 그 기록만 다시 씁니다 (예전에는 기록 전체를 매번 다시 썼음).
  - Windows 앱: 앱 데이터 폴더의 `history/index.json`(기록 순서)과 `history/<id>.json`(기록 하나). 모두 예전처럼 DPAPI로 암호화합니다.
  - 크롬 확장: 확장 저장소의 `history:index`와 `history:r:<id>` 칸.
- 처음 켤 때 예전 `history.json`(확장은 `history` 칸)을 옮깁니다. Windows 앱은 옮긴 것을 다시 읽어 개수가 맞을 때만 예전 파일을 지웁니다. 예전 파일을 남겨 두면 기록을 지워도 그 파일에 내용이 남기 때문입니다.
- 색인에 없는 기록 파일(지우는 도중 앱이 꺼진 경우)은 다음에 켤 때 정리합니다.
- **설정(`?`) › 기록 최대 개수**: 100 · 500(기본) · 1000 · 2000. 줄여서 지워질 기록이 있으면 몇 개가 지워지는지 먼저 묻습니다.

### 코드 구조

- 화면 코드 큰 파일을 나눴습니다. 동작은 같습니다.
  - `renderer.js` → `renderer.js`(도우미 · 모델 고르기 · 패널 · 자가진단 · 로컬 LLM) · `renderer-views.js`(비교 · 기록 · 설정 · 통계) · `renderer-compose.js`(종합 · 첨부 · 보내기 · 전체 상태)
  - `project.js` → `project.js`(상태 · 열기 · 트리 · 보내기 · NEED_FILES) · `project-changes.js`(변경 제안 · 변경 바 · 큰 작업 · 이어 받기 · 미리보기 · 적용 · 되돌리기 · 모아보기) · `project-editor.js`(편집기 · git 콘솔)
- Windows 앱 본체 `main.js`의 화면 요청(IPC) 처리 중 기록 · 프로젝트 · 설정을 `src/main/ipc/history.js` · `project.js` · `settings.js`로 옮겼습니다.
- **다국어 틀**: `src/shared/i18n.js`와 사전 `i18n-ko.js` · `i18n-en.js`. 새로 만드는 화면 글은 `t('키')`로 씁니다. 화면이 한국어와 영어로 섞이지 않게 아직은 한국어로 고정하고, 기존 화면 글은 v0.30.0에서 모두 옮긴 뒤 언어를 고를 수 있게 합니다.

### 개발

- **커밋 전 검사(pre-commit 훅)**: `src/`를 고치고 `npm run build:ext`를 잊었거나, 다시 만든 `extension/` 변경을 스테이지하지 않았으면 커밋을 멈춥니다. `npm install`(또는 `npm ci`) 때 `git config core.hooksPath scripts/hooks`가 자동으로 설정됩니다.
- 스크린샷 도구에 `MLA_SHOT_OUT=폴더`(문서 그림을 바꾸지 않고 다른 곳에 찍기)와 화면 스크립트 오류 출력을 더했습니다.

## 확인한 것

- `npm test` 279개 통과 (기록 저장 · 옮기기 · 최대 개수, 다국어 사전 짝, IPC 요청이 모두 한 번씩 연결됐는지 테스트 추가), `npm run check:ext` 통과.
- 실제 앱을 임시 프로필로 켜서 예전 `history.json`이 `history/` 폴더로 옮겨지고 예전 파일이 지워지는 것을 확인했습니다.
- 스크린샷 도구로 앱 화면 16개 장면(비교 · 분석 · 기록 · 설정 · 라이브러리 · 미리보기 · 로컬 LLM 등)을 나눈 파일로 띄워 화면 스크립트 오류가 없는 것을 확인했습니다.

## 알아 둘 것

- 기록 저장 형식이 바뀌어, v0.24.0으로 옮긴 뒤 예전 버전으로 되돌리면 그 버전은 기록을 빈 것으로 봅니다(새 형식을 모름).
- 크롬 확장은 실제 크롬에서 아직 확인하지 않았습니다(단위 테스트 · 생성 파일 검사만).

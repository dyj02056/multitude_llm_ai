크롬 확장에서 Qwen이 로그인돼 있어도 로그아웃 화면(로그인·가입 버튼)으로 뜨던 문제를 고친 버전입니다.

## 바뀐 점

- **크롬 확장: Qwen "로그인 필요" 문제 수정**
  - 원인: 크롬은 확장 탭 안 iframe을 "다른 사이트 안에 들어간 페이지"로 봅니다. 서버로 가는 요청에는 로그인 쿠키가 붙지만, 화면 스크립트가 `document.cookie`로 읽을 때는 SameSite=Lax/Strict 쿠키를 숨기고, 스크립트가 쓰는 일반 쿠키는 버립니다. Qwen은 화면 스크립트가 로그인 쿠키를 읽어 로그인 여부를 정하기 때문에 로그아웃 화면을 띄웠습니다. (Gemini·ChatGPT 등은 서버 쪽 쿠키만 써서 영향이 없었습니다.)
  - 해결:
    - 읽기: Qwen의 (HttpOnly가 아닌) 쿠키를 **이 확장 탭 안 iframe에서만 보이는 칸(partitioned 쿠키)**에 복사해 둡니다. 로그인·토큰 갱신·로그아웃이 생기면 자동으로 다시 맞춥니다.
    - 쓰기: iframe 안 Qwen이 쿠키를 쓰면 같은 칸에 바로 써서 읽히게 하고, 원래 쿠키에도 반영합니다 (그 페이지 도메인과 상위 도메인 쿠키만).
  - 복사한 쿠키는 일반 탭의 Qwen이나 다른 사이트에는 보이지도 붙지도 않습니다. 새 권한은 없습니다.

## 알아 둘 점

- 업데이트 뒤 앱 탭을 새로고침(또는 닫았다 다시 열기)해야 적용됩니다.
- 그래도 로그아웃 화면이면, 일반 탭에서 https://chat.qwen.ai 에 로그인한 뒤 Qwen 패널을 새로고침하세요.

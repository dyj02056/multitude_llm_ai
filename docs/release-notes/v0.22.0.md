큰 작업 · 잘린 답변 대응에서 **누르는 단계를 줄이는 옵션**과 **보낼 양 어림**을 넣었습니다 (프로젝트 모드).

## 바뀐 점

- **계획이 오면 바로 시작** (사이드바 › 큰 작업 아래, 프로젝트마다 기억): 계획 답(`PLAN_FILES`)이 오면 **▶ 파일별로 받기 시작**을 누르지 않아도 0.8초 뒤 한 파일씩 받기 시작합니다. 그사이 바의 ✕로 계획을 버리면 시작하지 않습니다.
- **잘리면 자동으로 이어 받기** (사이드바 옵션, 프로젝트마다 기억): 답이 출력 한도로 끊긴 파일이 생기면 **↪ 이어서 받기**를 누르지 않아도 같은 AI에게 나머지를 부탁합니다.
  - 같은 파일 · 같은 횟수에는 한 번만 보냅니다. 바를 다시 그려도 또 보내지 않습니다.
  - 한 파일 최대 3번까지만 하고, 넘으면 "다시 요청"을 안내합니다.
  - 이어 붙이기에 실패하면 자동으로 다시 보내지 않고 멈춥니다.
- **보낼 양 어림**: 사이드바 요약에 고른 파일의 대략적인 토큰 수가 나옵니다 (예: `≈ 1.4만 토큰`).
  - 파일 크기 ÷ 4로 어림합니다. 영어 · 코드는 약 4글자, 한글은 약 1.4글자가 1토큰 정도라 둘 다 비슷하게 나옵니다. 모델마다 실제 수는 다릅니다.
  - 1만 2천 토큰을 넘고 큰 작업이 꺼져 있으면 `[!] 큰 작업 권장`이 붙습니다.

## 확인한 것

- `npm test` 169개 통과: 토큰 어림 · 표시 글 · 권장 기준, 자동 이어받기가 같은 파일 · 같은 횟수에 한 번만 보내게 하는 규칙을 새로 시험합니다.
- 실제 AI 답으로 자동 진행이 이어지는지는 아직 확인하지 않았습니다. 부품 함수만 테스트로 확인했고, 화면 흐름은 코드를 읽어 확인했습니다.

AI별로 얼마나 잘 답하는지를 숫자로 보는 **응답 통계**와, 서비스 사용 한도에 걸렸을 때 알려 주는 **사용 한도 감지**를 넣었습니다.

## 바뀐 점

- **답변마다 숫자 기록** — 공통 입력창으로 보낸 질문의 답변마다 보내기 성공 여부, 첫 응답 시간(보낸 뒤 답변이 시작될 때까지), 완료 시간, 글자 수, 상태(완료 · 시간 초과 · 답변 없음 · 보내기 실패), 한도에 걸렸는지를 기록에 함께 남깁니다. 숫자만 남기고 글은 더 저장하지 않습니다.
- **AI별 응답 통계** — 설정(`?`) 화면에 표: 질문 수, 답변 완료(비율), 시간 초과 · 답 없음, 보내기 실패, 사용 한도, 첫 응답 · 완료까지 걸린 시간의 중앙값, 평균 글자 수. 프로젝트가 열려 있으면 이 프로젝트의 적용 기록에서 AI별 수정안 적용 · 되돌림 수도 보여 줍니다. 정확도 점수는 넣지 않았습니다 (앱이 맞는 답인지 알 수 없어서).
- 통계는 기록에서 계산하므로 **기록을 지우면 함께 지워집니다.** 이 PC에만 있습니다. v0.13.0 이전 기록에는 시간 정보가 없어 `–`로 나옵니다.
- **사용 한도 감지** — 답변이 끝나지 않았거나(답변 없음 · 시간 초과 · 보내기 실패) 400자 미만으로 짧게 끝났을 때만 화면에서 한도 안내 문구를 찾아, 패널 머리줄에 **⏳ 사용 한도에 걸린 것 같음**을 띄웁니다. 한도에 관한 질문의 긴 정상 답변은 보지 않습니다. 다음 답변이 정상으로 끝나면 지웁니다.
- 한도 문구는 서비스마다 원격 셀렉터 `limitText`(정규식)로 더하거나 고칠 수 있습니다.
- 설정 화면을 넓혀 표가 한눈에 들어오게 했습니다.
- Windows 앱과 크롬 확장 모두 같습니다.

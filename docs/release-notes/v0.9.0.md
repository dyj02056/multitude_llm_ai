내 템플릿(변수)과 스킬을 만들어 쓰는 라이브러리를 넣었습니다.

## 바뀐 점

- **📚 라이브러리** (툴바) — 템플릿 탭과 스킬 탭. 만들기 · 고치기 · 복제 · 삭제, 템플릿 즐겨찾기(☆). 기본 템플릿은 그대로 두고 **복제해서 고치기**로 내 것을 만듭니다.
- **템플릿 변수**
  - `{{언어}}` 보낼 때 입력받는 칸 · `{{관점|보안}}` 비우면 기본값 · `{{톤:간결,자세히}}` 고르기 목록
  - `{{오늘}}` · `{{프로젝트}}` · `{{선택 파일}}` 앱이 채우는 값 · `{q}` 입력창 내용 (예전과 같음)
  - 변수가 있는 템플릿으로 보내면 **변수 입력** 화면이 뜹니다 (미리보기, Enter 보내기 · Esc 취소). 템플릿마다 마지막 값을 기억합니다.
- **스킬** — 입력창 위 🧩 목록에서 고르면, 각 패널의 **새 대화 첫 질문**에 지침을 붙여 보냅니다 ("매 질문마다"로 바꿀 수 있음). ＋ · ⌂ · 모두 새 대화를 누르면 다음 질문에 다시 붙입니다. 11개 서비스 모두에 같은 방식으로 적용됩니다.
- **SKILL.md 가져오기 · 내보내기** — Claude 스킬과 같은 형식(맨 위 `---` 사이에 name · description)의 `.md` 파일을 여러 개 한 번에 가져오고, 스킬을 다시 `.md`로 저장합니다.
- **라이브러리 내보내기 · 가져오기** — 내 템플릿과 스킬을 `.json` 하나로 저장하고, 다른 PC에서 더합니다.
- 템플릿·스킬을 저장하거나 가져올 때 비밀 정보로 보이는 문자열이 있으면 확인합니다.
- 툴바가 좁아도 버튼 글자가 두 줄로 깨지지 않게 했습니다 (안내 문구가 먼저 줄어듦).

## 알아 둘 점

- 스킬은 각 서비스의 시스템 지시가 아니라 질문 글 앞에 넣는 방식입니다. 대화가 아주 길어지면 "매 질문마다"를 쓰세요.
- 스킬 본문은 2만 자까지입니다 (질문마다 그만큼 보내므로 짧을수록 좋습니다).
- ⌂(처음 주소로)도 이제 새 대화로 봅니다: 그 패널의 스킬과 프로젝트 파일을 다음 질문에 다시 보냅니다.

Gemini · ChatGPT · DeepSeek · Groq 웹 채팅을 한 화면에 띄워 같은 질문을 동시에 보내고 답변을 비교하는 Windows 앱의 첫 배포판입니다.

## 설치

1. 아래 **Assets**에서 `MultitudeLLM-Setup-0.1.0.exe`를 받아 실행합니다.
2. 코드 서명이 없어서 Windows SmartScreen 경고가 뜰 수 있습니다. **추가 정보 → 실행**을 누르세요.
3. 설치 폴더를 고르고 설치하면 바탕화면과 시작 메뉴에 바로가기가 생깁니다.

## 처음 쓸 때

1. Google 계정으로 로그인합니다.
2. 사용할 모델을 고릅니다.
3. 각 패널이 "Google로 계속하기"로 자동 로그인합니다. Google 계정 선택·동의 화면과 캡차(DeepSeek)는 직접 눌러 주세요.

## 기능

- 공통 입력창으로 선택한 모델에 질문 동시 전송, 보낼 대상 켜기/끄기
- 답변 완료 감지, 기다린 시간 표시, 답변 대기 시간 설정(기본 20분)
- 답변 복사 (Markdown — 표·코드 블록·목록 서식 유지), 모든 답변 한 번에 복사
- 교차검토(종합): 다른 AI 답변을 모아 한 AI에게 비교·정리 요청, 완료 후 자동 종합
- 답변 비교 화면, 질문 템플릿 8종
- 질문·답변 기록 저장·검색, Markdown 복사 (이 PC에만 저장)
- 단축키 (`Ctrl+/`로 목록 보기)
- 사이트 셀렉터 원격 갱신: 서비스 화면이 바뀌어도 앱 재설치 없이 고침

## 알아 둘 점

- 각 서비스의 무료 웹 채팅을 사용자 본인 계정으로 쓰며, 사용량 한도와 약관은 각 서비스를 따릅니다.
- 로그아웃하면 모든 서비스의 로그인 정보가 지워집니다. 질문·답변 기록은 남습니다.
- 자동 업데이트는 아직 없습니다. 새 버전은 이 페이지에서 받아 다시 설치하세요.

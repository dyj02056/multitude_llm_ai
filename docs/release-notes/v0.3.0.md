Mistral을 추가하고, 여러 AI에 보내는 질문에 이미지·문서 파일을 첨부할 수 있게 한 버전입니다.

## 바뀐 점

- **Mistral 추가**: [chat.mistral.ai/work](https://chat.mistral.ai/work) — 9개 서비스 중 최대 4개를 고릅니다.
- **파일 첨부**: 공통 입력창에 끌어다 놓기 · Ctrl+V(스크린샷) · 📎 버튼으로 올리면 보낼 대상 패널마다 첨부해서 보냅니다. 글 없이 파일만 보낼 수도 있습니다.
  - 한도: 최대 10개, 파일당 25MB, 합계 50MB
  - 첨부에 실패한 패널은 글만 보내고 `📎 첨부 없이 보냄`으로 표시합니다. 받지 않는 종류(예: Duck.ai의 문서)는 빼고 보냅니다.
  - 기록에는 첨부 파일 이름·크기만 남습니다.
- 크롬 확장 프로그램: 아래 **Assets**의 `MultitudeLLM-Extension-0.3.0.zip`을 풀어 `chrome://extensions`에서 다시 로드하세요 (이미 폴더로 쓰고 있다면 새 코드를 받은 뒤 ↻).

## 알아 둘 점

- Mistral과 각 서비스의 첨부 방법은 공개 자료를 바탕으로 넣었습니다. 사이트 화면이 다르면 `remote/selectors.json`(`upload` 항목)으로 앱 재설치 없이 고칩니다.

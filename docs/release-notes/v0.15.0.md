크롬 확장에서 **보고 있는 웹페이지로 질문**할 수 있게 했습니다.

## 바뀐 점

- 아무 웹페이지에서 오른쪽 클릭 › **Multitude LLM에 묻기 — 선택한 글**: 고른 글을 출처(제목 · 주소)와 함께 공통 입력창에 그대로 넣습니다. 끝의 `질문: ` 뒤에 이어 쓰면 됩니다.
- **— 이 페이지 본문**: 그 페이지의 본문 글을 `page.md`(제목 · 출처 · 가져온 때 + 본문)로 만들어 첨부하고, 입력창에 안내 한 줄을 넣습니다.
- 앱 탭을 열거나 앞으로 가져옵니다. 모델 고르기 화면이면 채팅 화면에 들어갈 때 넣고, 2분 넘게 지난 요청은 버립니다.
- 넣기 전에 비밀 정보 검사를 하고, 키 · 토큰처럼 보이는 것이 있으면 확인을 받습니다.
- **권한**: `contextMenus` · `activeTab` · `scripting`만 더했습니다. 모든 사이트 권한은 받지 않고, 업데이트 때 새 권한 확인 창이 뜨지 않습니다. 페이지 글은 "이 페이지 본문"을 누른 그 탭에서 그때만 읽고, 앱 탭이 가져가면 지웁니다.
- Windows 앱에는 이 메뉴가 없습니다.

Claude와 Z.ai를 더하고, 프로젝트 코드가 어느 서비스로 가는지 고를 수 있게 했습니다.

## 바뀐 점

- **Claude 추가** (`https://claude.ai/new`) — Windows 앱은 로그인 화면(`claude.ai/login`)의 "Google로 계속하기"를 대신 누릅니다. 이메일 로그인은 메일의 링크로 하므로 일반 브라우저나 크롬 탭에서 하세요.
- **Z.ai 추가** (`https://chat.z.ai/`) — 로그인하지 않아도(손님) 질문할 수 있습니다. 크롬 확장에서는 크롬에 로그인해 둔 Z.ai 토큰을 패널에 넣어 손님 대신 내 계정으로 엽니다.
- **프로젝트 파일을 보낼 서비스 고르기** — 사이드바의 "프로젝트 파일을 보낼 서비스"에서 끈 서비스에는 프로젝트 구조·파일을 보내지 않고 질문 글(과 직접 올린 첨부 파일)만 보냅니다. 그 서비스의 📂 요청 파일 보내기·전체 파일 다시 요청도 막습니다. 설정은 프로젝트마다 저장됩니다.
- **처음 올릴 때 확인** — 프로젝트 파일을 처음 받는 서비스가 있으면 "어느 서비스에 올라가는지"를 확인 창으로 보여 줍니다. 확인한 서비스는 그 프로젝트에서 다시 묻지 않습니다.

## 알아 둘 점

- Claude · Z.ai의 입력창·답변 셀렉터는 아직 실제 대화로 다 확인하지 못했습니다. 보내기나 "답변 완료" 표시가 안 맞으면 `remote/selectors.json`으로 고칩니다.
- Claude는 무료 사용량이 적고, 접속이 몰리면 Cloudflare 확인 화면이 뜰 수 있습니다 (패널에서 직접 누르세요).
- Z.ai는 중국 Zhipu AI가 운영합니다. 회사 코드라면 "보낼 서비스"에서 끄는 것을 검토하세요.

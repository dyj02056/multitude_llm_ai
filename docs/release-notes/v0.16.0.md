이 PC에서 돌아가는 LLM을 웹 패널과 나란히 쓰는 **로컬 LLM 패널**을 넣었습니다 (선택 기능, 기본은 꺼짐).

## 바뀐 점

- **켜기**: 설정(`?`) › 로컬 LLM (선택 기능) › **로컬 LLM 패널 쓰기** → 주소 확인 → **연결 확인**으로 모델 목록을 받아 고릅니다. 켜면 모델 선택에 **로컬 LLM**이 생깁니다.
- **연결**: OpenAI 호환 주소 하나로 Ollama(`http://localhost:11434`) · LM Studio(`http://localhost:1234`) · llama.cpp를 씁니다. 주소는 이 PC(localhost · 127.0.0.1 · [::1])만 받고, API 키와 바깥 주소는 받지 않습니다 — 질문과 프로젝트 코드가 PC 밖으로 나가지 않습니다.
- **패널**: 웹페이지 대신 앱이 말풍선 대화를 그립니다 (스트리밍, 제목 · 목록 · 표 · 코드 블록). 머리줄에서 모델 고르기 · ＋ 새 대화 · ■ 답 그만 받기.
- **함께 동작**: 공통 입력창 동시 질문, 종합 · 분석(판정 AI로도), 답변 비교 · 차이 강조, 기록, 응답 통계, 내보내기, 프로젝트 모드(파일 내용은 본문으로). 첨부는 이미지만(비전 모델일 때). 셀렉터 자가진단과 사용 한도 감지는 로컬 패널에는 쓰지 않습니다.
- 프로젝트 파일을 로컬 LLM에 보낼 때는 "회사 서버에 처음 올린다"는 확인을 묻지 않습니다 (이 PC 안이라서).
- **크롬 확장**: 켤 때만 이 PC 주소 접근 권한을 묻습니다 (선택 권한이라 설치 · 업데이트 때는 묻지 않음). Ollama는 `OLLAMA_ORIGINS=chrome-extension://*`로 켜야 확장에서 쓸 수 있습니다.
- 끄면 열린 로컬 패널을 닫고 고른 목록 · 종합 담당에서도 뺍니다.

Windows 앱에 프로젝트 폴더 전용 git 콘솔을 넣었습니다.

## 바뀐 점

- **⌥ git 콘솔** (프로젝트 사이드바 아래) — 열어 둔 프로젝트 폴더에서 git 명령을 실행합니다. `status` · `diff --stat` · `log` · `branch` 버튼, ↑↓ 이전 명령, 중지 버튼. 명령을 실행한 뒤에는 파일 트리를 다시 읽습니다.
- **git 명령만 받음** — 셸 없이 git.exe를 바로 실행합니다. 허용한 하위 명령만 받고(`clean`·`rebase`·`submodule`·`grep`·`help` 등은 안 됨), git 앞 옵션(`-c`, `-C` …), 외부 프로그램을 띄우는 옵션, 대화형 옵션, 설정 쓰기, 메시지 없는 commit은 막습니다.
- **확인 창** — `reset --hard`, `push --force`, `branch -D`, `checkout -- 경로`, `restore`, `stash drop`, `rm` 같은 되돌리기 어려운 명령은 실행 전에 앱 창 위에서 묻습니다.
- **git 훅 알림** — 콘솔을 열 때 그 저장소에 git 훅이 있으면 알려 줍니다 (commit 등을 실행하면 함께 실행되는 프로그램).
- **출력 가림** — `https://아이디:토큰@…` 주소와 알려진 키 모양(GitHub 토큰, AWS 키 등)은 화면에 가려서 보여 줍니다.
- **터미널 열기** — git 밖의 작업이 필요하면 그 폴더에서 Windows 터미널(없으면 PowerShell)을 엽니다.

## 알아 둘 점

- git이 설치되어 PATH에 있어야 합니다 (Git for Windows).
- `push`·`pull`에 로그인이 필요하면 Git 자격 증명 관리자 창이 뜹니다. 터미널로 비밀번호를 묻는 방식은 쓰지 않습니다.
- 크롬 확장 프로그램에는 git 콘솔이 없습니다 (확장 프로그램은 프로그램을 실행할 수 없음).

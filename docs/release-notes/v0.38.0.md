# v0.38.0 — 로드맵 (계획서 → 단계 → 진행 그림 → 문서)

프로젝트 계획서를 단계별 작업으로 쪼개고, 진행 상황을 그림으로 보고, `docs/procedure.md` · `README.md`를 프로젝트 폴더에 만들어 주는 **로드맵** 창을 더했습니다. 사용법은 [로드맵 안내](../roadmap.md).

## 바뀐 점

- **계획서 분해** — 계획서(붙여 넣기 · `PLAN.md` 불러오기 · `.md` `.txt` 파일)와 프로젝트 구조를 AI에게 보내 마일스톤 → 작업(선행 · 파일 · 완료 조건 · 크기) JSON으로 받고, 앱이 읽어 검사합니다(JSON 없음 · 작업 없음 · 선행 순환은 거절, 빈 완료 조건 · 큰 작업은 경고). 선행은 id로도 제목으로도 쓸 수 있습니다.
- **작업 진행** — 상태 5가지(대기 · 진행 중 · 검증 중 · 완료 · 막힘). 선행이 끝나지 않은 작업은 진행 · 검증 · 완료로 못 바꿈. **구현 요청**은 작업 요청 글을 입력창에 채울 뿐 보내지 않고(보내기 · 변경 확인 · 적용 · 테스트는 프로젝트 모드 그대로 사람이 확인), 예상 파일 중 있는 것을 고른 파일에 넣음. 편집 · 위아래 · 합치기 · 추가 · 삭제(선행이 돌고 돌게 되는 편집은 거절).
- **진행 그림 4가지** — 진행 링(가중치 기준 %) · 마일스톤 누적 막대 · 선행 관계 지도 · 번다운(+ 추정 완료일). 인라인 SVG, 상태마다 색 + 기호, HTML 내보내기.
- **문서 만들기** — `docs/procedure.md`(개요 · 단계 표 · 단계별 상세 · 진행 요약 + mermaid · 변경 이력)와 `README.md`(소개 · 주요 기능 · 진행 현황 · 폴더 구조 · 사용 방법). 사실은 앱이 채우고 소개 문장만 AI에게 부탁. **표식 주석 안쪽만 갱신**해 내가 쓴 글을 지키고, 표식 없는 기존 README는 기본으로 `README.generated.md`에 따로 씀(끝에 붙이기 · 교체는 설정 + 미리보기 확인). 쓰기 전 비밀 정보 검사, 실패하면 원래대로, 방금 쓴 문서 되돌리기.
- **설정** — 문서 자동 생성(켬) · 갱신 시점(작업 완료마다) · 기존 README 처리(별도 파일) · 문서 언어 · mermaid · 작업 단위 자동 커밋(끔, Windows 앱).
- **저장** — 진행 데이터는 프로젝트 폴더의 `.mla/roadmap.json`. `.mla/`는 AI에게 보내는 파일에서 항상 제외(L1).
- 한국어 · 영어 화면, 접근성(탭 `role="tab"` · 방향키, 창 `role="dialog"`, 지도 칸 키보드 사용).

## 알아 둘 점

- 웹 채팅의 AI는 폴더를 직접 고치지 못하므로 **완전 자동 구현이 아니라 단계마다 사람이 확인하는 반자동**입니다.
- 진행률 · 예상 완료일은 추정입니다. PDF 계획서는 직접 읽지 않습니다. 자동 커밋은 Windows 앱 전용.
- 새 파일: `src/shared/roadmap.js` · `roadmap-charts.js` · `roadmap-docs.js`, `src/renderer/roadmap-ui.js`. 새 테스트 2개(`roadmap.test.js` · `roadmap-ui.test.js`).

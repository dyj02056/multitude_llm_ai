프로젝트 파일을 앱 안에서 바로 고치고, 로컬 저장과 AI 탭 반영을 한 번에 할 수 있게 한 버전입니다.

## 바뀐 점

- **인앱 편집기** — 프로젝트 사이드바 트리에서 **파일 이름**을 누르면 편집 화면이 열립니다 (사이드바는 그대로 보여서 다른 파일로 바로 옮겨 갈 수 있습니다).
  - **저장** (Ctrl+S): 로컬 파일에 씁니다. 적용 기록에 `직접 편집`으로 남아 **되돌리기**가 됩니다.
  - **저장하고 AI에 보내기**: 저장한 뒤, 이 파일을 받은 적 있는 AI 탭에 지금 내용을 보냅니다 (v0.6.0의 "바뀐 파일 보내기"와 같은 확인·비밀 검사).
  - **다시 읽기**: 고친 내용을 버리고 디스크에서 다시 엽니다.
  - 열어 둔 뒤 다른 프로그램에서 파일이 바뀌었거나 지워졌으면, 저장할 때 덮어쓸지 묻습니다.
  - 원래 줄바꿈(CRLF/LF)을 지키고, Tab 키는 파일이 쓰는 들여쓰기(탭 / 공백 2칸 / 4칸)로 넣습니다.
  - 저장하지 않은 내용은 패널로 돌아가도(Esc 포함) 남아 있고, 같은 파일을 다시 누르면 이어서 고칠 수 있습니다. 다른 파일을 열거나 프로젝트를 닫을 때는 확인을 받습니다.
- 앱 내장 제외 규칙(L1: `.env`, `.git`, `node_modules` 등)에 걸린 파일은 열지 않습니다.

## 알아 둘 점

- 편집기는 단순한 글 상자입니다 (문법 색칠·자동 완성 없음).

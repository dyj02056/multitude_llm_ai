고칠 파일이 많거나 길어 한 답에 다 못 쓰는 작업을 **계획 먼저 받고 파일별로 나눠 받는** "큰 작업"을 넣었습니다.

## 바뀐 점

- 프로젝트 사이드바 아래 **큰 작업 — 계획 먼저 · 파일별로 받기** (프로젝트마다 기억). 꺼져 있어도 고른 파일이 4개를 넘거나 합계 600줄을 넘으면 한 번 권합니다.
- 켜고 질문하면 이번 답은 **코드 없이 계획만** 오게 부탁합니다: 설명 몇 줄, 파일마다 `- 경로: 할 일`, 맨 끝 `PLAN_FILES: 경로1, 경로2, …`.
- 계획 답이 오면 변경 바에 `🗂 계획: 파일 N개`와 **▶ 파일별로 받기 시작**.
- 시작하면 "계획대로 1/N번째 파일만 줘: 경로 — 할 일"을 보내고, 답이 끝날 때마다 모은 뒤 다음 파일을 보냅니다 (`⏳ 파일별로 받는 중 i/N`). 각 파일은 답변 규칙대로(짧은 파일은 전체, 긴 파일은 찾기/바꾸기).
- 다 받거나 **멈추기**를 누르면 모은 수정안을 한 묶음으로 바에 보여 줍니다 (`🗂 파일별로 받음 M/N`) — 미리보기 · 테스트 실행 · 적용, 잘린 파일은 이어서 받기.
- **건너뛰기**로 지금 파일을 빼고 다음으로. 답이 시간 초과 · 답변 없음으로 끝나면 자동으로 넘어가지 않으니 멈추기나 건너뛰기를 누르세요.
- 여러 패널이 각자 따로 진행하고, 그 패널에서 새 대화를 열면 멈춥니다. 앱 내장 제외 경로는 계획에 있어도 받지 않습니다.

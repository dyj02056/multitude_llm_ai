Genspark를 추가하고 Poe를 뺐으며, 크롬 확장에서 Grok이 대화를 시작하지 못하던 문제를 고친 버전입니다.

## 바뀐 점

- **Genspark 추가** ([genspark.ai/ko](https://www.genspark.ai/ko)) — 9개 서비스 중 최대 4개 선택은 그대로입니다.
- **Poe 제거** — 예전 설정에 Poe가 골라져 있었다면 자동으로 빠집니다. 모델 선택 화면에서 다른 모델을 하나 더 고르세요.
- **크롬 확장: Grok "네트워크에서 Grok을 차단하고 있습니다 (timeout)" 오류 수정**
  - 원인: 크롬은 확장 탭 안 iframe의 페이지·API 요청에는 로그인 쿠키를 붙이지만, WebSocket 연결에는 SameSite=Lax 로그인 쿠키를 붙이지 않습니다. Grok은 답변을 WebSocket으로 주고받아 로그인되지 않은 연결로 보고 실패했습니다.
  - 해결: 앱 탭 안·서비스 도메인·WebSocket 요청에 한해, 크롬이 그 사이트에 가진 쿠키를 그대로 붙이는 규칙을 겁니다. 쿠키가 바뀌면 자동으로 다시 맞추고, 앱 탭을 떠나면 지웁니다. 이를 위해 `cookies` 권한과 서비스 `wss://` 접근 권한이 추가됐습니다.
- Windows 앱: 보내는 사이 패널을 닫으면 오류가 날 수 있던 부분을 고쳤습니다.

## 알아 둘 점

- 권한이 늘어나서 크롬이 확장 프로그램을 다시 사용 설정하라고 물을 수 있습니다. `chrome://extensions`에서 켜 주세요.
- Genspark의 입력창·보내기 버튼·답변 위치는 공개 자료를 바탕으로 넣었습니다. 보내기 버튼을 못 찾으면 Enter 키로 보냅니다.

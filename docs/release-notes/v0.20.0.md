Windows 앱에 **자동 업데이트**를 넣었습니다. 크롬 확장은 새 버전이 있으면 알려 줍니다.

## 바뀐 점

- **Windows 앱**: 앱을 켜고 30초 뒤, 그다음 6시간마다 GitHub Releases에 새 버전이 있는지 확인합니다.
  - 새 버전이 있으면 툴바 상태줄에 `update 0.20.1`이 뜹니다. 누르면 설정 화면으로 갑니다.
  - 설정(`?`) › **업데이트**에서 **다운로드** → **다시 시작해서 설치**를 누릅니다. 받아 둔 업데이트는 앱을 그냥 닫을 때도 설치됩니다.
  - **알리기만** 하고 저절로 받거나 설치하지 않습니다. 답변을 기다리는 중에 앱이 꺼지지 않게 하려는 것입니다.
  - **새 버전 자동 확인**을 끄면 **지금 확인**을 누를 때만 확인합니다.
  - 개발 실행(`npm start`)에서는 확인하지 않습니다.
- **크롬 확장**: 압축해제 방식이라 스스로 바뀔 수 없습니다. GitHub main의 버전만 보고 새 버전이 있으면 알립니다. 업데이트는 저장소를 `git pull`한 뒤 `chrome://extensions`에서 ↻를 누르면 됩니다. 권한은 더 받지 않습니다.
- **안전**: 코드 서명이 없어 서명 검사는 하지 않습니다. 받은 설치 파일은 GitHub Releases(HTTPS)의 `latest.yml`에 적힌 해시(sha512)와 맞을 때만 설치됩니다.
- **처음 한 번은 직접 설치**해야 합니다. 자동 업데이트는 v0.20.0을 손으로 설치한 다음 릴리스부터 동작합니다.

## 확인한 것

- `npm test` 159개 통과: 버전 비교 · 상태 글 · "알리기만, 누를 때만 받기 · 설치" 규칙 · 개발 실행에서 확인 안 함 · 빌드 설정.
- 실제 설치 파일 빌드: 앱 안에 `app-update.yml`(GitHub 저장소), 결과물에 `latest.yml`(sha512) · `.blockmap`이 생기는 것을 확인했습니다. 릴리스 워크플로는 이미 이 파일들을 올립니다.
- 실제 업데이트 과정은 다음 릴리스를 올린 뒤 확인이 필요합니다.

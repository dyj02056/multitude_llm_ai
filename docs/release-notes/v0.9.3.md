AI 답변의 파일 코드를 모아 복사하는 **📋 파일 모아보기**를 넣고, `.md` 파일이 여러 코드 블록으로 쪼개지던 문제를 고쳤습니다.

## 바뀐 점

- **📋 파일 모아보기** — 답변에 파일 코드(`파일: 경로` 코드 블록 · diff · `DELETE_FILES:`)가 있으면 답변이 끝날 때 패널 머리줄에 **📋 파일 N개 모아보기** 버튼이 생깁니다. 누르면 파일마다 **새 파일 / 수정 / 변경 없음 / 삭제** 표시와 전체 코드가 모이고, **경로 복사 · 코드 복사 · 전체 복사**(파일 목록 + `파일: 경로` + 코드 블록)로 바로 붙여 넣을 수 있습니다. 파일에는 쓰지 않습니다.
  - 프로젝트를 열어 두면 지금 파일과 비교해 새 파일·수정을 나누고, AI가 바뀐 부분만(diff) 줘도 지금 파일과 합친 완성된 전체 코드로 보여 줍니다.
  - 프로젝트를 열지 않아도 씁니다 (이때는 AI가 준 코드 그대로 "전체 코드"로 표시).
  - 변경 제안 화면의 AI별 칸에도 **📋 모아보기** 버튼을 넣었습니다.
- **버튼 효과** — 모아보기 버튼이 나타날 때 튀어나오고 네 번 반짝인 뒤, 누를 때까지 테두리가 은은하게 빛납니다. Windows의 "애니메이션 효과 줄이기"를 켜면 움직이지 않습니다.
- **새 기본 템플릿 "코드 수정 (파일 모아보기)"** — 모아보기에 잘 잡히는 형식으로 답을 받습니다: 파일 목록 [새 파일]/[수정]/[삭제], 파일마다 `파일: 경로` + 전체 코드 블록 하나, 코드 생략 금지, 한 파일은 블록 하나, 지울 파일은 `DELETE_FILES:`.
- **`.md` 파일이 여러 코드 블록으로 쪼개지던 문제 수정**
  - 답변 규칙(프로젝트 모드 · 코드 리뷰 템플릿 · 새 템플릿)에 "한 파일은 블록 하나, 안에 ``` 가 든 파일은 바깥 울타리를 백틱 4개로"를 추가했습니다.
  - AI가 백틱 4개로 올바르게 감싸도 앱이 답변을 읽을 때 백틱 3개로 다시 감싸 블록이 쪼개지던 것을 고쳤습니다. 이제 내용에 ``` 가 있으면 더 긴 울타리를 씁니다 (모아보기 · 변경 제안 · 답변 복사 모두 적용).
- **코드 리뷰 템플릿** — 고친 파일마다 `파일: 경로`를 적어 달라고 요청해, 답변이 모아보기·변경 제안에 잡히게 했습니다.

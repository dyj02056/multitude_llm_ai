v0.4.4의 Qwen 토큰 다리를 실제 Qwen 쿠키 구성에 맞춘 버전입니다.

## 바뀐 점

- **Qwen: `refresh_token` 쿠키 지원** — 실제 Qwen에는 `token` 쿠키가 없고 `refresh_token` 쿠키(로그인 시 생기는 30일짜리 토큰)만 있었습니다. 이 값도 Qwen 서버가 로그인 토큰으로 받아 주므로, `token`이 없으면 `refresh_token`을 패널의 `localStorage.token`에 넣습니다. Qwen 화면이 이후 새 토큰으로 스스로 갈아 끼웁니다.
- 패널에 아직 만료되지 않은 토큰이 있으면 건드리지 않고, 없거나 만료됐을 때만 넣고 한 번 새로고침합니다.

## 알아 둘 점

- `chrome://extensions`에서 확장 프로그램을 새로고침(↻)한 뒤(버전 0.4.5) 앱 탭도 새로고침하세요.

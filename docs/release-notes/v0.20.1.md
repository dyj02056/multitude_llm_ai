문서 스크린샷을 **지금 화면(CLI 디자인)**으로 다시 찍고, 앞으로도 한 번에 다시 찍을 수 있는 도구를 넣었습니다.

## 바뀐 점

- **`npm run screenshots`**: 실제 화면 코드에 가짜 본체와 예시 데이터를 붙여 Electron 창에 띄우고, 장면마다 `docs/screenshots/*.png`로 저장합니다.
  - 일부만 찍을 수도 있습니다: `npm run screenshots -- 02-ask-all`
  - 패널 안은 실제 AI 사이트가 아니라 **테스트용 채팅 페이지**입니다. 실제 사이트에는 접속하지 않습니다.
- **다시 찍은 장면 16개**: 모델 고르기 · 동시 질문 · 종합 · 답변 비교 · 분석 · 차이 강조 · 기록 · 설정 · 첨부 · 라이브러리 · 수정안 미리보기 · 로컬 LLM · 서비스 화면 상태 · 응답 통계 · 로컬 LLM 설정 · **사이드탭(새 그림)**.
- README 화면 표에 사이드탭 · 차이 강조를 넣고, 예전 화면 안내를 고쳤습니다.
  - 프로젝트 모드 일부(09 · 10 · 16 · 21~23)와 크롬 확장 탭(08)은 프로젝트 폴더나 확장 환경이 필요해서 아직 예전 화면입니다.
- 이 버전은 v0.20.0 자동 업데이트를 처음 시험하는 릴리스이기도 합니다.

## 확인한 것

- `npm test`: 테스트용 채팅 페이지가 글을 이스케이프하는지, 장면마다 그림이 있는지, README · docs가 가리키는 그림이 모두 있는지 확인합니다.
- 찍은 그림을 하나씩 열어 확인했습니다.

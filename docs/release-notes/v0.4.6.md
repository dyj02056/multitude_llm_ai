크롬 확장의 Qwen 로그인 문제를, 실제 브라우저 오류 기록으로 확인한 원인에 맞춰 고친 버전입니다.

## 바뀐 점

- **Qwen: `auth.qwen.ai` 도메인 추가**
  - 원인: Qwen의 로그인 화면과 로그인 확인 요청이 `chat.qwen.ai`가 아니라 `auth.qwen.ai`에서 처리됩니다. 확장 프로그램에 그 도메인 접근 권한이 없어서
    - 패널 안 "로그인"을 누르면 앱 탭 보안 정책(CSP)이 로그인 화면을 막았고,
    - 패널에서 `auth.qwen.ai`로 가는 요청에 크롬이 로그인 쿠키(SameSite=Lax)를 붙이지 않아 로그아웃 상태로 보였습니다.
  - 해결: Qwen의 도메인에 `auth.qwen.ai`를 넣었습니다. 패널 안 로그인 화면이 뜨고, 그 요청에도 로그인 쿠키가 붙습니다.
- 토큰 다리(v0.4.4~)는 Qwen 채팅 화면(`chat.qwen.ai`)에만 동작합니다 (로그인 화면에는 넣지 않음).

## 알아 둘 점

- 접근 권한이 늘어 크롬이 확장 프로그램을 잠시 꺼 둘 수 있습니다. `chrome://extensions`에서 다시 켜 주세요.
- 패널 안 로그인 화면에서 "Google로 로그인"은 Google이 iframe을 막아 안 될 수 있습니다. 일반 탭에서 https://chat.qwen.ai 에 로그인한 뒤 패널을 새로고침하는 방법이 가장 확실합니다.
- 콘솔의 `Permissions policy violation: unload is not allowed` 줄은 Qwen 보안 스크립트가 남기는 경고로, 동작에는 영향이 없습니다.

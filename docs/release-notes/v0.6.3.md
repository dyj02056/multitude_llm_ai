AI 수정안이 git 내부 파일을 바꾸지 못하게 막은 보안 버전입니다.

## 바뀐 점

- **`.git` 안쪽에는 쓰지 않음** — AI가 답변에 `파일: .git/hooks/pre-commit`이나 `.git/config`를 넣으면, 적용한 뒤 다음 `git commit`·`git pull` 때 그 내용이 코드로 실행될 수 있었습니다. 이제 `.git` 폴더 안쪽 경로(대소문자, Windows 짧은 이름 `GIT~1` 포함)는 변경 제안에서 빠지고, 파일 쓰기·지우기(편집기 저장 포함)도 거절합니다. `.git/info/exclude` 같은 읽기는 그대로입니다.
- **`.gitmodules`도 실행 영향 파일** — 하위 모듈 주소가 바뀌면 받아 오는 코드가 바뀌므로 `⚠` 표시와 기본 체크 해제 대상에 넣었습니다.

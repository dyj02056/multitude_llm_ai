프로젝트 모드에서 AI 수정안을 **패널 안에서 바로 적용**할 수 있게 했습니다. 이제 변경 제안 화면으로 옮겨 가지 않아도, 답변이 끝나면 그 패널 아래에서 한 번에 파일을 씁니다.

## 바뀐 점

- **패널 아래 변경 바** — 프로젝트를 열어 두고 답변에 수정안(`파일: 경로` 코드 블록 · diff · `DELETE_FILES:`)이 있으면, 답변이 끝날 때 그 패널 아래에 바가 올라옵니다. 바뀌는 파일 수와 +/− 줄 수, 파일 이름이 한 줄로 보이고, 마우스를 올리면 파일별 내용이 나옵니다. AI 페이지는 바 높이만큼 짧아져 바를 가리지 않습니다.
  - **적용 (N)** — 미리보기 창에서 기본으로 체크되는 파일만 바로 씁니다. 실행에 영향을 주는 파일(`package.json` 실행 항목, CI 설정, git 훅 등)과 파일 삭제는 바로 쓰지 않고 `⚠ N개 확인 필요`로 표시합니다.
  - **변경 보기** — 지금까지의 미리보기·적용 창을 엽니다. 파일마다 바뀌는 줄을 보고 골라서 적용합니다.
  - **📋** — 파일 모아보기 (프로젝트가 열려 있으면 머리줄 버튼 대신 바 안에 있습니다).
  - **✕** — 바를 닫습니다. 수정안은 변경 제안 화면에서 그대로 볼 수 있습니다.
  - diff가 맞지 않는 등 적용할 수 없는 파일은 `N개 적용 불가`로 알리고, 그런 파일만 있으면 **변경 제안에서 보기**로 바로 갑니다 (전체 파일 다시 요청).
- **적용됨 · 되돌리기** — 적용하면 바가 초록색 `✓ N개 파일 적용됨`으로 바뀌고 **되돌리기**가 붙습니다. 되돌리면 적용 전 내용으로 돌아가고(새로 만든 파일은 지움) 바는 다시 적용할 수 있는 상태가 됩니다. 변경 제안 화면에서 적용해도 패널로 돌아가면 같은 바가 보입니다.
- **다른 AI의 바도 바로 갱신** — 한 AI의 수정안을 적용하거나 되돌리면, 아직 적용하지 않은 다른 패널의 바를 지금 파일 기준으로 다시 계산합니다 (이미 같은 내용이 된 파일은 빠짐).
- **파일 트리 표시** — 이번에 AI 수정안으로 바꾼 파일에 `M`(수정) · `A`(새 파일)를 붙입니다. 되돌리면 지웁니다.
- **미리보기·적용 창** — 열면 **선택한 파일 적용** 버튼에 포커스가 가서 Enter로 바로 적용합니다. **Ctrl+Enter**도 됩니다 (모아보기 창에서는 전체 복사).
- **변경 제안 화면** — 이미 적용한 수정안을 `⚠ 적용 불가` 대신 `✓ 적용됨`으로 표시합니다.
- 새 질문을 보내거나, 답변이 다시 시작되거나, 새 대화를 열면 그 패널의 바는 내려갑니다 (적용한 것은 **적용 기록**에서 계속 되돌릴 수 있음).
- Windows 앱과 크롬 확장 모두 같습니다.

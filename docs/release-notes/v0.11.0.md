답변 비교 화면에 **분석** 탭과 **차이 강조**를 더했습니다. 여러 AI의 답이 어디서 같고 어디서 갈리는지 한눈에 봅니다.

## 새 기능

- **분석 탭** — 답변 비교 화면 왼쪽 위 **답변 | 분석** 탭. 분석 탭의 **분석 요청**을 누르면 종합 담당 AI(입력창 아래 **종합** 목록)에게 다른 AI들의 답변을 보내고, 정해진 형식으로 답하게 합니다.
  - **이견** — 쟁점마다 AI별 입장과 판단을 표로 보여 줍니다. 표의 칸이나 AI 이름을 누르면 **답변** 탭의 그 AI 칸으로 이동해 잠깐 빛납니다. 이견이 없으면 "이견이 없습니다"라고 알려 줍니다.
  - **공통 의견** · **근거 부족**(AI 이름 표시) · **최종 답변**(복사 버튼)
  - 탭 이름에 이견 수가 붙습니다 (`분석 · 이견 2`).
  - 판정 AI가 형식을 지키지 않으면 "정해진 형식이 아니라서 글 그대로 보여 줍니다"와 함께 답변 글을 그대로 보여 줍니다.
  - 분석하는 동안 분석 탭에 "분석하는 중…"이 보이고, 끝나면 바로 표로 바뀝니다. 다른 화면에 있어도 입력창 아래에 끝났다고 알려 줍니다.
- **분석 기록** — 분석 결과는 질문 기록에 함께 저장됩니다. **기록** 화면에서 그 질문을 고르면 답변 칸 위에 같은 분석 표가 나오고, 목록에는 `분석 1`처럼 표시됩니다. Markdown 복사에도 `## 분석 (판정 AI)`로 들어갑니다.
- **차이 강조** — 답변 탭 위쪽 **차이 강조**를 켜면 기준 답변에 없는 문장만 노란 형광으로 표시합니다.
  - 기준 답변은 처음엔 첫 칸이고, 옆의 `기준:` 목록에서 바꿉니다.
  - 칸 머리줄에 `기준` 또는 `다름 N%`가 붙습니다.
  - 띄어쓰기 · 줄바꿈만 다른 문장은 같은 것으로 봅니다. 목록처럼 마침표가 없는 줄은 한 줄씩 비교합니다.
- 탭 위치와 차이 강조 켜짐은 다음에 비교 화면을 열 때도 그대로입니다.

Windows 앱과 크롬 확장 모두 같습니다.

화면 디자인을 새로 바꿨습니다. 기능은 그대로이고, 처음 보는 사람도 어디를 먼저 볼지, 무엇을 누를지 한눈에 알 수 있게 색 · 버튼 · 움직임을 다듬었습니다.

## 바뀐 점

- **바탕과 질감** — 아주 어두운 남색 바탕에 보라 · 청록 빛이 은은하게 번집니다. 툴바 · 공통 입력창 · 패널 · 카드는 반투명 유리판처럼 떠 보이고, 툴바와 입력창 가장자리에 네온 선이 흐릅니다. 패널 머리줄에는 서비스 고유 색이 번집니다.
- **버튼 4단계** — 중요한 버튼과 일반 버튼을 한눈에 구분합니다.
  - **주요**(보내기 · 선택한 모델 열기 · 저장 · 적용): 빛나는 보라→청록 그라데이션
  - **일반**(기록 · 답변 비교 · 라이브러리 등): 유리 버튼
  - **보조**(모든 답변 복사 · 모두 새 대화 · 모두 새로고침, 패널 머리줄의 ← ⌂ ↻ 등): 평소엔 테두리 없음
  - **위험**(로그아웃 · 삭제): 붉은 톤
  - 지금 연 화면의 툴바 버튼(기록 · 답변 비교 · 변경 제안 · 라이브러리 · ?)은 보라빛으로 켜집니다. 툴바 버튼은 묶음마다 세로 구분선으로 나눴습니다.
- **버튼 반응** — 마우스를 올리면 살짝 떠오르며 빛나고, 누르면 꾹 눌리듯 작아집니다. 키보드(Tab)로 고르면 청록 테두리가 보입니다.
- **공통 입력창** — 둥근 입력칸을 누르면 둘레에 보라~청록 빛이 켜집니다. 보내기 버튼은 `보내기 ➤`. 보낼 대상 칩은 켜면 서비스 색으로 빛나고 끄면 흐려집니다. **종합 요청**은 청록 테두리로 따로 눈에 띕니다.
- **답변 비교 · 기록을 채팅처럼** — 내 질문은 오른쪽 그라데이션 말풍선, AI 답변은 말풍선 카드로 바뀌고 왼쪽부터 하나씩 스르륵 올라오며 나타납니다. 기록 목록도 차례로 나타나고, 고른 기록은 보라빛으로 표시됩니다.
- **모델 선택 화면** — 큰 제목 아래 "이렇게 씁니다" 설명 카드 3장(모델 고르기 → 한 번에 질문 → 비교 · 종합)을 넣고, 모델은 2열 카드로 바꿨습니다. 고른 카드는 서비스 색으로 빛납니다.
- **설정 · 단축키** — 설정 한 줄을 작은 카드로, 설명 문구는 왼쪽 보라 줄이 있는 안내로, 단축키는 키캡 모양으로 바꿨습니다.
- **움직임** — 화면이 켜질 때 페이드인, 창(미리보기 · 모아보기)은 살짝 커지며 열리고, 프로젝트 사이드바는 왼쪽에서 밀려 나옵니다. 답변 중이면 패널 머리줄의 상태 점이 물결처럼 퍼집니다.
- **움직임 줄이기** — Windows 설정 › 접근성 › 시각 효과 › **애니메이션 효과**를 끄면 모든 움직임이 꺼집니다.
- Windows 앱과 크롬 확장 모두 같습니다. 패널 안의 AI 웹페이지는 각 서비스 화면 그대로입니다.

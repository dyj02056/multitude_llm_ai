v0.10.1~v0.12.0 기능을 Windows 앱에서 직접 점검하고 찾은 문제를 고쳤습니다.

## 고친 점

- **분석이 끝나지 않으면 버튼이 잠기던 문제** — 판정 AI가 시간 초과 · 답변 없음으로 끝나면 분석 탭의 "분석하는 중" 표시가 지워지지 않아 **분석 요청**을 다시 누를 수 없었습니다. 이제 "분석 실패: …이(가) 시간 안에 답하지 않았습니다"처럼 이유를 보여 주고 다시 요청할 수 있습니다. 시간 초과 뒤 늦게 답이 끝나면 그 결과로 바뀝니다.
- **자가진단 오탐** — 네트워크 오류나 오류 페이지에서도 모든 패널이 "⚠ 화면이 바뀐 것 같음"으로 뜨던 문제를 고쳤습니다. 페이지 불러오기에 실패한 패널은 살펴보지 않고, 페이지를 살펴보기만 했을 때는 △ 주의까지만 표시합니다. ✕ 못 찾음은 실제로 질문을 보낼 때 입력창을 못 찾았거나, 답변을 2번 연달아 못 찾았을 때만입니다.
- **테스트 실행 확인 창의 경고** — 체크한 수정안이 `package.json`의 test · pretest · posttest를 바꾸면 `test: 이전 → 이후`로, git 훅 · CI 설정처럼 실행에 영향을 주는 파일이 들어 있으면 그 파일과 이유를 ⚠로 따로 보여 줍니다. "적용 후" 실행에서는 바뀐 스크립트가 돌기 때문입니다.
- **Electron 프로젝트의 테스트** — 테스트를 npm과 같은 Node 설치의 `node.exe`로 실행합니다. 예전에는 앱 자신을 Node처럼 실행하는 설정(`ELECTRON_RUN_AS_NODE`)이 테스트 전체에 물려가, 테스트 안에서 Electron을 띄우는 프로젝트가 오동작할 수 있었습니다. `node.exe`를 못 찾을 때만 예전 방식을 씁니다.
- **차이 강조** — 표현만 조금 다른 문장("Python을 추천합니다" · "Python을 추천해요")은 새 내용으로 보지 않습니다 (글자 겹침으로 판단, 숫자가 다르면 새 내용). 칸 머리줄은 `새 내용 N%`.
- **로그인 팝업** — Apple(`idmsa.apple.com`) · Microsoft(`login.microsoft.com`, `account.live.com`) 로그인이 중간에 거치는 주소와 나라별 Google 로그인(`accounts.google.co.jp` 등)을 허용 목록에 넣었습니다. 로그인 창이 허용 밖 주소(회사 SSO 등)로 가면 기본 브라우저로 열고 패널에 알려 줍니다.
- **크롬 확장 프로젝트 상태** — v0.10.0까지 확장이 모든 프로젝트 상태를 한 곳에 저장하던 것을, 업데이트 뒤 처음 여는 폴더로 옮깁니다 (고른 파일 · 제외 규칙이 사라지지 않게).
- README에 분석 탭 · 차이 강조 · 서비스 화면 상태 · 테스트 실행 스크린샷을 넣었습니다.

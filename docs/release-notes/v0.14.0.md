기록 · 답변 비교 · 분석 결과를 파일로 저장하는 **내보내기**를 넣었습니다.

## 바뀐 점

- **기록** 화면: 고른 기록의 **MD 저장** · **HTML 저장** — 질문, 첨부 파일 이름, AI별 답변, 종합 결과, 마지막 분석.
- **답변 비교** 화면 위쪽 **MD 저장** · **HTML 저장** — 지금 질문, 열린 패널의 최신 답변, 이번 질문의 분석.
- **Markdown**: 메모 앱 · 문서에 붙여 넣기 좋은 글. 기록 화면의 **Markdown 복사**도 같은 내용(분석 포함)으로 바뀌었습니다.
- **HTML**: 파일 하나로 완결되는 밝은 문서 모양. 분석은 이견 표 · 공통 의견 · 근거 부족 · 최종 답변으로, 답변의 제목 · 목록 · 표 · 코드 블록을 살립니다. 브라우저에서 인쇄(Ctrl+P) › PDF로 저장하면 PDF가 됩니다.
- **안전**: 답변 속 태그(`<script>` 등)는 모두 글자로 바꿔 넣고, HTML 파일에는 스크립트 · 바깥 파일(글꼴 · 그림)이 하나도 없으며 스크립트를 막는 보안 설정(CSP)을 넣습니다.
- **저장 방법**: Windows 앱은 저장 창(처음 위치는 다운로드 폴더), 크롬 확장은 크롬의 다운로드 (권한을 더 받지 않음). 파일 이름은 `날짜 질문 앞부분.md`.

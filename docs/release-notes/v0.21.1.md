사이트 화면이 바뀌었을 때 **무엇이 안 되는지 보고 바로 고쳐 볼 수 있게** 했습니다.

## 바뀐 점

- **자가진단 창**: 패널 머리줄의 `⚠ 화면이 바뀐 것 같음`이나 `[limit] 사용 한도에 걸린 것 같음`을 누르면 열립니다. 예전에는 설정 화면으로 넘어가기만 했습니다.
  - 입력창 · 보내기 버튼 · 답변 영역마다 찾음 / 다른 방법으로 됨 / 못 찾음, 그리고 안내를 보여 줍니다.
  - 지금 쓰는 셀렉터 버전, 마지막 확인 시각, 실패 이유를 보여 줍니다.
  - 버튼: **셀렉터 지금 확인**(GitHub에서 고친 셀렉터를 바로 받아 봄) · **처음 화면으로** · **진단 정보 복사** · **전체 상태**(설정의 표) · **닫기**
  - **진단 정보 복사**에는 서비스 · 앱 버전 · 실행 환경 · 셀렉터 버전 · 찾은/못 찾은 항목만 들어갑니다. 질문 · 답변 글과 대화 주소는 넣지 않습니다.
  - Windows 앱에서는 미리보기 창처럼 패널을 잠깐 치우고 띄웁니다. 웹페이지에 가려지지 않게 하려는 것입니다.
- **새 셀렉터 알림**: 원격 셀렉터를 새 버전으로 받으면 툴바 상태줄에 `selectors v<번호>`가 10초 동안 뜹니다.
- **고치는 순서 문서**: [remote/README.md](../../remote/README.md)에 "사이트 화면이 바뀌었을 때 고치는 순서"를 더했습니다 (진단 정보 받기 → 재현 → 셀렉터 찾기 → 고치기 · 버전 올리기 → 로컬 시험 → 올리기).

프로젝트 모드의 AI 답변 형식을 **파일별 전체 내용**으로 바꾸고, 로컬에서 바뀐 파일을 AI 탭에 바로 보내는 기능을 넣은 버전입니다.

## 바뀐 점

- **답변 형식: diff → 파일별 전체 내용** — AI에게 바꾸거나 새로 만든 파일마다 `파일: 경로` 줄 다음에 수정한 **전체 내용**을 코드 블록 하나로 달라고 합니다 ("..."로 줄이지 말 것). 지울 파일은 `DELETE_FILES: 경로` 한 줄로 받습니다.
  - 적용 범위: 첫 질문·📂 요청 파일 보내기의 답변 규칙, 변경 제안의 **종합으로 합치기**, 입력창 템플릿 **코드 리뷰**.
  - AI가 규칙과 달리 diff로 주어도 예전처럼 읽어서 적용합니다. 미리보기 창에서는 그대로 바뀌는 줄(+/−)을 보여 줍니다.
- **⟳ 뒤 바뀐 파일 바로 보내기** — 앱이 AI마다 받은 파일 내용을 기억해 두고, 사이드바 ⟳(다시 읽기) 때 로컬 파일과 비교합니다. 직접 고쳤거나 다른 AI의 수정안을 적용해 달라진 파일이 있으면 사이드바 아래에 **⇪ 바뀐 파일 N개 → AI N곳에 보내기**가 뜹니다.
  - 누르면 AI별 목록을 확인한 뒤, 그 탭들에 지금 내용을 업로드(올리는 방식 설정 그대로)하고 지운 파일은 목록으로 알립니다. AI에게는 "아직 수정하지 말고 확인만" 부탁합니다.
  - 비밀 정보 검사는 다른 전송과 같습니다. 수정안을 낸 AI는 적용 결과를 이미 아는 것으로 봅니다. 패널에서 새 대화(＋)를 열면 그 AI의 기록은 지웁니다.

## 알아 둘 점

- 전체 내용 형식은 큰 파일일수록 답변이 길어집니다. 서비스의 답변 길이 한도에 걸려 잘리면 그 파일은 끝이 빠진 채로 보이니, 미리보기에서 끝부분이 지워지는지 확인하세요. 큰 파일의 작은 수정은 요청에 "diff로 줘"라고 적으면 예전 방식으로도 받을 수 있습니다.
- 기억은 앱을 켜 둔 동안만 유지합니다 (앱을 다시 켜면 처음부터).

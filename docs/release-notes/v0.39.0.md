# v0.39.0 — 화면 정리: 틀은 그대로, "터미널 흉내" 장식과 영문 약어를 걷어 냄

v0.19.0부터 쓰던 어두운 단색 · 1px 선 · 각진 모서리 틀과 툴바(44px) · 입력창(132px) · 패널 머리줄(28px) 높이는 그대로 두고, 화면이 "자동으로 만든 것"처럼 보이게 하던 장식을 뺐습니다. Windows 앱 · 크롬 확장 · 사이드탭, 한국어 · 영어 화면 모두 같습니다.

## 바뀐 점

- **기호 장식 제거** — 입력창 · 비교 질문 · 기록 질문 · 첫 화면 제목 앞의 `❯`, 툴바 이름 뒤 `~/chat` 경로와 앞의 초록 점, 모델 목록의 `[x]` / `[ ]`, 설정 · 분석 · 도움말 제목 앞 `##`, 라이브러리 묶음 앞 `#`, 보내기 버튼의 `⏎`, 프로젝트 이름 앞 `~/`, 버튼 글의 `[+]` · `[!]` · `[img]` · `[f]`를 뺐습니다.
- **버튼 글자를 낱말로** — 툴바 `grid · row · main · 2col · lib · proj · diff · hist · cmp · copy · new · reload · side · models`를 `격자 · 가로 · 큰 칸 · 2열 · 라이브러리 · 프로젝트 · 변경 제안 · 기록 · 비교 · 복사 · 새 대화 · 새로고침 · 사이드탭 · 모델`(영어: `Grid · Row · Main · 2 col · Library · Project · Changes · History · Compare · Copy · New chat · Reload · Side tab · Models`)로. 상태 줄 `2/3 ready` → `3개 중 2개 준비됨` / `2 of 3 ready`. 패널 머리줄 `copy` → `복사`, 프로젝트 `proj:이름` → `프로젝트: 이름`, `skill:` · `preset:` · `tpl:` → `스킬` · `프리셋` · `템플릿`, `flow` → `작업 흐름`, 수정안 바 `collect` → `모아 복사`. 사이드탭의 `models · app ↗ · ctx: · on/off · send`도 사전(ko · en)에서 옵니다.
- **글꼴 둘로** — 화면 글자는 본문 글꼴(Pretendard가 깔려 있으면 그것, 없으면 Segoe UI · 맑은 고딕). 고정폭 글꼴은 주소 · 코드 · 파일 경로 · 숫자 · 스킬 본문에만 씁니다. 한국어는 낱말 중간에서 줄을 바꾸지 않습니다(`keep-all`).
- **색** — GitHub 다크 그대로였던 색(`#0d1117` · `#58a6ff` · `#3fb950`)을 푸른 기를 뺀 회색 + 강조색 하나로 바꿨습니다. 글자색은 모두 가장 밝은 바탕에서도 4.5:1 이상(테스트가 확인). 숫자 칸 · 날짜 칸 같은 기본 부품도 어두운 모양(`color-scheme: dark`).
- **서비스 색 표시** — 패널 머리줄 · 비교 칸 · 미리보기 · 토론 참가자의 왼쪽 2px 색 띠를 이름 앞 작은 사각형으로. 둥근 점은 상태(준비 · 답변 중 · 오류)만 뜻합니다.
- **첫 화면** — 제목 위 `# 머리말`과 `01 · 02 · 03` 카드 세 장 대신, 제목 아래 설명 한 문단(고른 AI만 열림 · 한 번에 보내기 · 비교 화면). 모델 목록은 진짜 체크 상자.

## 좁은 창 · 넘침 점검

버튼 글이 길어져서, 앱의 가장 작은 창(960px)과 기본 크기(1400px)에서 한국어 · 영어 장면을 모두 찍어 넘치는 곳을 고쳤습니다.

- **툴바**: 1100px 아래에서는 상태 글(패널 머리줄에도 있음)과 구분선을 숨기고 글자 · 간격을 줄여 960px에서도 `로그아웃` / `Log out`까지 한 줄에 들어갑니다. 그래도 넘치면 옆으로 밀어 볼 수 있습니다(막대는 숨김).
- **비교 · 변경 제안 · 라이브러리 머리줄**: 좁으면 두 줄로 내려갑니다. 전에는 `차이 강조` 같은 버튼 글이 한 글자씩 세로로 쪼개졌습니다.
- **입력창 윗줄**: 좁으면 `Enter 보내기 …` 안내 글이 먼저 줄어들고(…), 종합 · 토론 · 작업 흐름 버튼 묶음은 줄지 않습니다.
- **기록 왼쪽 아래 버튼**: 글자가 두 줄로 쪼개지지 않고, 모자라면 버튼이 다음 줄로.
- 첫 화면 설명이 `있습니/다`처럼 낱말 중간에서 끊기던 것.

## 알아 둘 점

- 패널 안의 AI 웹페이지는 각 서비스 화면 그대로라 이 디자인이 적용되지 않습니다.
- 패널 머리줄의 `← ⌂ ↻ { }` 같은 아이콘 버튼과 즐겨찾기 `★`는 그대로 둡니다(설명이 aria-label · 마우스 설명에 있음).
- 960px 창에서 패널 머리줄의 상태 글(`답변 완료 · 219자`)은 전처럼 `…`로 줄어듭니다.
- 문서 그림(`docs/screenshots`, 영어 `docs/screenshots/en`)을 새 모양으로 다시 찍었습니다. 크롬 웹 스토어 그림(`store/screenshots`)과 홍보 타일도 새 모양으로 다시 찍었습니다.

로컬 프로젝트 폴더를 열어 여러 AI와 함께 코드 작업을 하는 **프로젝트 모드**를 넣은 버전입니다. Windows 앱과 크롬 확장 프로그램 모두 됩니다.

## 바뀐 점

- **📁 프로젝트**: 로컬 폴더를 열면 왼쪽에 파일 트리가 뜹니다. 고른 파일 내용과 프로젝트 구조를 질문에 함께 보냅니다 (10만 자가 넘으면 `project-context.md`로 첨부).
- **3단계 제외 규칙**: L1 항상 제외(비밀·키·바이너리·1MB 초과·.git·node_modules) · L2 기본 적용(.gitignore 계열, .cursorignore 등 AI 전용 ignore, 새 `.mlaignore`) · L3 선택 적용(.dockerignore·.npmignore 등, 기본 꺼짐). 빠진 이유를 파일·줄 번호까지 보여 줍니다.
- **비밀 정보 검사**: 키·토큰·개인 키로 보이는 문자열이 있으면 경고하고 확인을 받아야만 보냅니다.
- **NEED_FILES**: AI가 답변 끝에 더 볼 파일을 적으면 패널에 "📂 요청 파일 N개 보내기" 버튼이 생깁니다.
- **변경 제안** (Ctrl+Shift+P, 확장은 Alt+Shift+P): AI별 코드 수정안을 비교 → 미리보기 → 고른 파일만 적용. 맞지 않는 diff는 "전체 파일 다시 요청", 여러 안은 "종합으로 합치기".
- **적용 기록·되돌리기**: 최근 20개 적용을 되돌릴 수 있습니다 (git은 건드리지 않음).

## 알아 둘 점

- AI가 폴더를 직접 열어 보는 것이 아니라, 앱이 고른 내용만 대화에 넣습니다. 코드가 선택한 AI 서비스들로 전송된다는 점을 알고 쓰세요.
- 크롬 확장은 앱 탭을 새로 열 때마다 사이드바의 "폴더 접근 허용"을 한 번 눌러야 합니다 (크롬 정책).
- 포함 라이브러리: ignore 7.0.12 (MIT), jsdiff 9.0.0 (BSD-3-Clause).

사이드탭이 **보고 있는 탭을 자동으로 읽게** 했습니다 (Gemini 사이드 패널처럼).

## 바뀐 점

- 사이드탭 맥락 줄의 **자동 읽기 켜기**를 한 번 누르면, 크롬이 "사이트 데이터 읽기" 허용을 묻습니다. 허용하면 이렇게 동작합니다.
  - 탭을 옮기거나 지금 탭의 페이지가 다 열릴 때마다 그 탭 본문을 다시 읽어 `ctx:` 줄에 보여 줍니다.
  - 질문을 보낼 때마다 지금 탭을 다시 읽어, 그 패널에 처음 보내는 페이지(또는 글이 바뀐 페이지)면 본문을 함께 보냅니다. 같은 페이지로 이어 묻는 질문은 글만 보냅니다.
  - 크롬 설정 · 웹 스토어 · 빈 탭처럼 읽을 수 없는 탭에서는 페이지 없이 보냅니다.
- 허용하지 않으면 예전처럼 **Alt+Shift+S** · 오른쪽 클릭 메뉴로 가져온 그 탭만 씁니다.
- **권한**: 사이트 읽기 권한(`http://*/*` · `https://*/*`)은 **선택 권한**입니다.
  - 설치 · 업데이트 때는 묻지 않고, **자동 읽기 켜기**를 누를 때만 묻습니다.
  - `chrome://extensions` › Multitude LLM › 세부정보 › 사이트 액세스에서 언제든 끌 수 있고, 끄면 사이드탭이 바로 예전 방식으로 돌아갑니다.
- 같은 페이지를 다시 읽어도 본문이 같으면 다시 보내지 않도록, "보낸 페이지"를 주소 + 본문 내용으로 구분합니다.

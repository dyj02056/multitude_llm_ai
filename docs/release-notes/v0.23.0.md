프로젝트 모드에서 **바뀐 파일만 보내고**, 여러 파일 적용이 중간에 실패하면 **자동으로 되돌립니다**. 답변 평가(`[+1]`/`[-1]`)와 만족도, 원격 셀렉터 서명 검사를 더했고, 버그 9건과 보안 · 성능을 보강했습니다.

## 새 기능

- **바뀐 파일만 보내기** (프로젝트 사이드바, 기본 켬): 두 번째 질문부터 패널마다 그 뒤로 바뀐 파일만 올리고, 그대로인 파일은 `[앞서 보낸 그대로]` 목록으로 알립니다. 끄면 예전과 같습니다.
- **이어지는 질문에 지난 파일 목록 붙이기** (선택): 파일을 고르지 않은 후속 질문에도 지난번에 보낸 파일 목록(줄 수)을 붙이고, 바뀐 것은 다시 올립니다.
- **적용 트랜잭션**: `적용 (N)` · 미리보기 `적용`에서 한 파일이라도 쓰기에 실패하면 이미 쓴 파일을 모두 원래대로 되돌리고 어느 파일이 왜 실패했는지 알립니다.
- **답변 평가**: 답변이 끝난 패널 머리줄의 `[+1]` 좋았음 · `[-1]` 별로였음. 설정(`?`) › AI별 응답 통계에 **만족도** 열(`75% (3/4)`).
- **원격 셀렉터 서명**: `remote/selectors.json.sig`(Ed25519)를 검사해 맞지 않으면 적용하지 않고 지금 값을 유지합니다. 저장소 주인이 `npm run selectors:keygen`으로 키를 만들기 전까지는 꺼져 있습니다 ([remote/README](../../remote/README.md#서명)).

## 고친 문제

- git 콘솔 · 테스트 실행: 확인 창이 떠 있는 동안 두 번째 명령이 같이 실행되던 문제.
- git · 테스트 출력: 한글이 조각 경계에서 깨지고, 경계에 걸린 토큰이 가려지지 않던 문제.
- 폴더 고르기 창을 취소하면 열려 있던 프로젝트 경로가 지워지던 문제.
- 크롬 확장 사이드탭: 보내기 중 오류가 나면 보내기 버튼이 계속 잠기던 문제.
- 크롬 확장: 백그라운드가 다시 시작된 뒤 WebSocket 쿠키 규칙 번호가 겹쳐 규칙이 걸리지 않던 문제.
- 크롬 확장: **로컬 LLM 패널이 페이지 CSP에 막혀 연결되지 않던 문제** (`localhost` · `127.0.0.1` 허용, `[::1]`은 CSP 문법상 불가).
- 답변 감시: 페이지를 계속 읽지 못하면 시간 초과 판정 없이 끝나지 않던 문제.
- 종료 직전 0.5초 안의 기록이 저장되지 않던 문제.

## 보안 · 안정성

- 본체가 화면에서 온 첨부(형식 · 개수 · 크기), 파일 읽기 상한, 로컬 LLM 주소를 다시 검사합니다.
- 프로젝트 파일 쓰기: 임시 파일에 쓴 뒤 이름 바꾸기. 테스트 실행 수정안 합계 50MB 상한.
- 수정안 읽기: 찾기/바꾸기 안에 `=======`만 있는 줄이 있어도 파일에 한 곳만 맞는 쪽으로 나누고, 애매하면 적용하지 않습니다. diff 안의 `-- …`/`++…` 내용 줄을 파일 머리로 잘못 읽지 않습니다. NEED_FILES/PLAN_FILES의 `../` 같은 경로는 버립니다.
- 비밀 정보 검사: 글 전체를 보고 20개까지 보고(종류마다 하나 먼저), 한 줄에 여러 종류, Anthropic · OpenAI 프로젝트 · npm 토큰 · Azure 연결 문자열 · Bearer 토큰 · `*_TOKEN=`/`*_PASSWORD=` 대입 추가, 예시 값 제외.

## 성능

- 업로드 나누기(3MB 한 줄): 519ms → 15ms. 같은 이름 2000개 정리: 722ms → 2ms.
- 폴더 목록의 파일 크기 읽기 병렬(16개씩), 제외 규칙 판정 캐시.
- 설정 · 라이브러리 · 기록 저장을 0.3초 모아 비동기로 (종료 때는 동기로 마저 씀).
- 로컬 LLM 스트리밍은 한 프레임에 한 번만 그리고, 위로 올려 읽는 중이면 아래로 끌어내리지 않습니다.
- 긴 diff 미리보기는 2000줄씩, `더 보기 (남은 N줄)`.

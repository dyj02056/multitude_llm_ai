코드 작업을 더 안전하게 하는 개발자 기능을 넣었습니다. 수정안을 적용하기 전에 테스트를 돌려 보고, 필요한 부분만 골라 적용하고, AI 사이트 화면이 바뀌면 바로 알려 줍니다.

## 새 기능

- **테스트 실행** (Windows 앱) — 미리보기 창(변경 제안 **미리보기·적용** · 패널 바의 **변경 보기**)에 **테스트 실행** 버튼을 넣었습니다.
  - 확인 창에서 실행할 스크립트와 폴더를 보여 준 뒤, **적용 전**(지금 파일 그대로)과 **적용 후**(체크한 수정안을 잠깐 써 둔 상태)로 `npm test`를 두 번 실행합니다.
  - 끝나면 성공 · 실패 · 중지와 상관없이 **원래 파일로 되돌립니다.** 실제 적용은 결과를 보고 **선택한 파일 적용**으로 합니다.
  - 결과를 나란히 보여 줍니다: 통과 · 실패 · 시간 초과, 통과/실패 수, 걸린 시간, 출력. 위에 `✓ 수정안이 실패하던 테스트를 고칩니다`, `⚠ 수정안을 쓰면 테스트가 깨집니다` 같은 한 줄 판정이 붙습니다.
  - `package.json`의 `test` 스크립트만 실행합니다. 셸을 거치지 않고 앱 자신으로 npm(`npm-cli.js`)을 실행합니다 (Node.js 설치 필요). 시간 제한 3분, 출력 2MB, 출력의 토큰 · 키는 가립니다. **테스트 중지**로 멈출 수 있습니다.
  - 테스트 중에 앱이 꺼져도 원본을 따로 적어 두었다가 다음에 그 프로젝트를 열 때 되돌립니다.
  - AI가 고친 코드(테스트 코드 포함)가 이 PC에서 실행되므로, 내용을 확인한 뒤 실행하세요.
- **덩어리 단위 적용** — 수정하는 파일에 바뀐 곳이 둘 이상이면 미리보기 창에 `덩어리 N개`와 덩어리마다 체크 상자가 나옵니다. 고른 덩어리만 씁니다. 파일 체크 상자는 덩어리 전체를 켜고 끄고, 일부만 고르면 `−` 모양이 됩니다. 되돌리기는 지금처럼 파일 단위입니다.
- **셀렉터 자가진단** (Windows 앱 · 크롬 확장) — 패널마다 입력창 · 보내기 버튼 · 답변 영역을 찾았는지 기록합니다.
  - 못 찾은 것이 있으면 패널 머리줄에 **⚠ 화면이 바뀐 것 같음**이 뜹니다. 마우스를 올리면 무엇을 못 찾았는지와 해결 방법이 보이고, 누르면 설정 화면으로 갑니다.
  - 설정(`?`) 화면에 **서비스 화면 상태** 표가 생겼습니다 (✓ 찾음 · △ 다른 방법으로 됨 · ✕ 못 찾음 · – 확인 전).
  - 답변 영역은 두 번 연달아 못 찾았을 때만 ✕로 봅니다. 원격 셀렉터를 새 버전으로 받으면 다시 확인합니다.

크롬 확장 프로그램 배포 전 보안 점검에서 나온 문제를 고친 버전입니다. 평소 사용 흐름과 속도는 그대로입니다.

## 고친 점

- **앱 탭을 떠나면 iframe 허용 규칙을 즉시 해제** — 앱 탭에서 다른 사이트로 이동하면, 그 사이트가 로그인된 AI 사이트를 자기 페이지 안에 넣을 수 있던 문제를 막았습니다. 새로고침·백그라운드 재시작에도 규칙이 꼬이지 않습니다.
- **요청 파일 보내기 확인** — AI가 요청한 파일은 "보낼 파일 / 보내지 않을 파일과 이유" 목록을 확인한 뒤에만 보냅니다. 비밀 정보로 보이는 파일은 기본으로 뺍니다.
- **"전체 파일 다시 요청" 검사** — 앱 내장 제외 파일은 보내지 않고, 다른 제외 규칙·비밀 정보 의심 파일은 확인을 받습니다.
- **실행 영향 파일 보호** — CI 설정·git 훅·`.vscode`·Makefile·Dockerfile·스크립트 파일, `package.json`의 실행 항목(`scripts` 등) 변경, 파일 삭제는 적용 창에서 `⚠` 표시와 함께 기본으로 체크하지 않습니다. 의존성만 바꾼 `package.json`은 그대로 체크됩니다. "모두 선택" 버튼을 추가했습니다.
- **원격 설정 범위 축소** — 보내기·로그인 버튼과 파일 선택 칸 셀렉터는 원격으로 바꾸지 않고, 새 대화 주소는 그 서비스 도메인만 받으며, 위험한 정규식은 거절합니다.
- **iframe 범위·권한 축소** — 앱 탭에는 9개 서비스 도메인만 iframe으로 뜹니다. 클립보드 읽기 권한을 뺐습니다 (붙여넣기·음성 입력은 그대로).
- **Windows 앱 정리** — 첨부 임시 파일을 시작·종료 때 지우고, Windows 특수 경로(`:`·`CON` 등)를 거절합니다.

## 바뀐 사용감

- 요청 파일 보내기와 제외된 파일 다시 요청에 확인 창이 한 번 더 뜹니다.
- 사이트가 보내기 버튼 모양을 바꾸면 원격 설정 대신 앱 업데이트로 고칩니다 (그 사이에도 Enter 키로 보내는 예비 동작으로 대부분 작동).

v0.4.3으로도 크롬 확장의 Qwen이 로그아웃 화면으로 뜨던 문제를, 실제 원인을 다시 찾아 고친 버전입니다.

## 바뀐 점

- **크롬 확장: Qwen "로그인 필요" 문제 수정 (실제 원인)**
  - v0.4.3에서 고친 것: iframe 안 화면 스크립트가 로그인 쿠키를 읽지 못하는 문제. 이것만으로는 부족했습니다.
  - 실제 원인: Qwen 화면은 쿠키가 아니라 **`localStorage.token`** 값을 `Authorization` 헤더로 보내 로그인을 확인합니다. 크롬은 확장 탭 안 iframe의 저장소(localStorage)를 일반 탭과 분리할 수 있어서, 일반 탭에서 로그인해도 iframe 쪽에는 토큰이 없었습니다.
  - 해결: Qwen 서버는 같은 토큰을 `token` 쿠키에도 넣어 둡니다. 크롬이 가진 그 쿠키 값을 앱 탭 안 Qwen iframe에만 알려 주어 그 iframe의 localStorage에 넣고, 한 번만 새로고침합니다 (무한 새로고침 방지 장치 포함).
  - 토큰은 Qwen 자신의 iframe에만 전달되며 다른 사이트·일반 탭·외부로 보내지 않습니다. 새 권한은 없습니다.

## 알아 둘 점

- `chrome://extensions`에서 확장 프로그램을 새로고침(↻)한 뒤 앱 탭도 새로고침해야 적용됩니다.
- 일반 탭의 https://chat.qwen.ai 에서 로그인돼 있어야 합니다. 열면 Qwen 패널이 한 번 깜빡이며 새로고침된 뒤 로그인 상태로 보입니다.

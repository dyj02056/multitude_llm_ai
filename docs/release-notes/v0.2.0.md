서비스를 8개로 늘리고(최대 4개 선택), 크롬 확장 프로그램으로도 쓸 수 있게 한 버전입니다.

## 바뀐 점

- **Groq → Grok**: Groq 플레이그라운드 대신 [grok.com](https://grok.com/)을 씁니다.
- **새 서비스**: Perplexity · Qwen · Poe(기본 봇) · Duck.ai
- **최대 4개 선택**: 8개 중 4개까지 고를 수 있고, 처음 값은 Gemini · ChatGPT · DeepSeek · Perplexity입니다. 예전 설정의 Groq는 Grok으로 바뀌고 4개가 넘으면 앞의 4개만 남습니다.
- **크롬 확장 프로그램**: 아래 **Assets**의 `MultitudeLLM-Extension-0.2.0.zip`을 풀고 `chrome://extensions` → 개발자 모드 → **압축해제된 확장 프로그램을 로드합니다**로 그 폴더를 고릅니다. 크롬에 로그인된 각 서비스 계정을 그대로 씁니다.
- 격자(2×2) · 가로(1×4) 배치는 Windows 앱과 확장 프로그램 모두 그대로 씁니다.

## 알아 둘 점

- 새 서비스(Perplexity · Grok · Qwen · Poe · Duck.ai)의 입력창·답변 셀렉터는 공개 자료를 바탕으로 넣었습니다. 사이트 화면이 다르면 `remote/selectors.json`으로 앱 재설치 없이 고칩니다.
- 확장 프로그램에서는 `모두 새 대화`가 `Alt+Shift+N`, `N번째 대상 켜기/끄기`가 `Alt+Shift+1~4`입니다 (크롬이 `Ctrl+Shift+N`, `Ctrl+1~9`를 페이지에 넘겨주지 않음).
